# PDF fonts

DocPilot loads PDF regeneration fonts from this directory with `fetch()`.

- Noto Sans KR: SIL Open Font License 1.1
- Nanum Gothic: SIL Open Font License 1.1
- Nanum Myeongjo: SIL Open Font License 1.1
- Malgun Gothic: Microsoft Windows font. Not bundled by default. User must provide the file only if licensed.

Expected open font files:

- `NotoSansKR-Regular.ttf`
- `NanumGothic-Regular.ttf`
- `NanumMyeongjo-Regular.ttf`

Optional user-provided file:

- `MalgunGothic-Regular.ttf`

Malgun Gothic is a Microsoft Windows font. Do not redistribute it without proper license. If you own the right to use it, place `MalgunGothic-Regular.ttf` here manually.
