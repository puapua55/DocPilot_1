DocPilot 금일 작업 이력
작성일: 2026-09-13

1. DOCX 뷰어 줄/문단 간격 보정
- DOCX 원본의 줄 간격, 문단 전/후 간격이 뷰어에 반영되지 않던 문제를 재확인했다.
- docxService.js에서 DOCX 문단 스타일 정보를 더 많이 읽도록 보강했다.
- WordViewer.css에서 문단/라인 렌더링 스타일을 보정해 원본 문서의 간격을 최대한 따라가도록 수정했다.

관련 파일
- frontend/src/services/docxService.js
- frontend/src/components/WordViewer.css


2. PDF 즉시 텍스트 교체 미리보기 박스 크기 보정
- 기존에는 교체된 글자 박스가 드래그한 원본 텍스트 영역보다 크게 잡히는 문제가 있었다.
- 교체 영역을 기존 텍스트 Range의 실제 좌표 기준으로 계산하도록 수정했다.
- 커버 영역은 드래그된 원본 텍스트 영역만큼만 지우도록 조정했다.
- 교체 글자는 별도 오브젝트처럼 overlay 레이어에 올리고, 배경 커버와 글자 레이어를 분리했다.
- 원본 글자는 배경색으로 덮은 뒤 교체 글자를 다시 그리는 방식으로 정리했다.

관련 파일
- frontend/src/services/highlightService.js
- frontend/src/components/PdfPage.jsx
- frontend/src/services/pdfReplacementFont.js


3. PDF 뷰어 확대/축소 비율 대응
- 뷰어 확대/축소 시 교체 글자의 위치와 크기가 원본 글자와 함께 비율에 맞게 바뀌도록 수정했다.
- PDF 페이지의 현재 CSS 픽셀 좌표를 기준으로 교체 레이어를 만들고, 페이지 스케일 변경 시 같이 재배치되도록 정리했다.
- 한글 교체 텍스트가 브라우저/다운로드 양쪽에서 깨지거나 다른 폰트로 보이는 문제를 줄이기 위해 NotoSansKR 기반 교체 폰트를 사용하도록 했다.

관련 파일
- frontend/src/components/PdfPage.jsx
- frontend/src/services/pdfReplacementFont.js
- frontend/src/services/highlightService.js


4. 교체 텍스트 자동 폭 계산 및 폰트 축소
- 사용자가 요청한 범위인 "기존 텍스트 영역 + 같은 줄의 다음 텍스트 위치 + 표 셀 경계"를 함께 계산하도록 구현했다.
- 같은 줄 다음 텍스트의 시작 위치를 Range 좌표로 찾는다.
- 표 셀의 오른쪽 경계는 PDF canvas 픽셀을 검사해 세로선을 탐지한다.
- 가능한 최대 폭을 계산한 뒤, 교체 글자가 넘칠 경우 해당 폭 안에 들어가도록 폰트 크기를 자동 축소한다.
- 교체 글자가 들어갈 공간이 없으면 무리하게 그리지 않도록 방어 처리했다.

관련 파일
- frontend/src/services/pdfReplacementLayout.js
- frontend/src/services/highlightService.js
- frontend/tests/pdf-replacement-layout.test.mjs


5. PDF 뷰어 우측 상단 "변환 다운로드" 버튼 추가
- 첨부 이미지에서 표시한 PDF 뷰어 우측 상단 영역에 별도 "변환 다운로드" 버튼을 추가했다.
- 이 버튼은 현재 화면에 적용된 교체 텍스트를 기준으로 원본 PDF 위에 overlay 방식으로 반영한다.
- 화면에 교체 적용이 없는 경우 다운로드를 막고 안내 메시지를 표시하도록 했다.

관련 파일
- frontend/src/components/PdfJsViewer.jsx
- frontend/src/components/DocumentViewer.jsx
- frontend/src/App.jsx
- frontend/src/App.css


6. 원본 PDF 유지형 overlay 변환 방식 추가
- "PDF 원본 편집"이 아니라 원본 PDF를 유지한 상태에서 선택 영역만 덮고 새 글자를 그리는 변환 방식을 추가했다.
- pdf-lib와 fontkit을 사용해 원본 PDF 페이지를 유지하고, 교체 영역에 배경색 사각형과 교체 텍스트를 그린다.
- 화면의 replacement-layer DOM 좌표를 수집해 PDF 페이지 좌표로 변환한다.
- 페이지 회전값도 고려해 좌표를 변환한다.
- canvas에서 교체 영역의 배경색과 글자색을 샘플링해 하이라이트 배경 위에서도 자연스럽게 보이도록 했다.
- 한글 다운로드 결과가 비어 보이는 문제를 줄이기 위해 폰트 subset 옵션을 끄고 전체 폰트를 embed하도록 조정했다.

관련 파일
- frontend/src/services/pdfOverlayConvertService.js
- frontend/package.json
- frontend/package-lock.json
- frontend/tests/pdf-overlay-regression.spec.js


7. "즉시 텍스트 교체" 모달의 "변환 파일 다운로드" 흐름 확인 및 보강
- 사용자가 확인한 "변환 파일 다운로드"는 ReplaceModal.jsx의 버튼이며, App.jsx의 handleReplaceConvert를 통해 documentReplaceService.convertTextReplacement로 연결된다.
- 현재 이 흐름은 PDF -> HTML 위치/텍스트 구조 추출 -> 텍스트 치환 -> jsPDF 재생성 방식이다.
- 적용된 변환 파일명은 예시처럼 *_html_converted.pdf 형태로 생성된다.
- 뷰어에서 사용자가 만든 하이라이트 정보를 이 변환 흐름에도 전달하도록 연결했다.

관련 파일
- frontend/src/App.jsx
- frontend/src/components/DocumentViewer.jsx
- frontend/src/components/PdfJsViewer.jsx
- frontend/src/services/documentReplaceService.js
- frontend/src/services/pdfHtmlStructureService.js
- frontend/src/services/pdfHtmlTextConvertService.js


8. HTML/jsPDF 재생성 방식의 하이라이트 적용
- 원본 PDF의 Highlight annotation을 추출해 HTML 구조에 포함하도록 구현했다.
- 뷰어에서 만든 CSS 하이라이트도 현재 페이지 크기 기준으로 수집해 변환 단계에 넘기도록 했다.
- HTML 구조에 pdf-highlight 요소를 추가하고, jsPDF 렌더링 시 텍스트보다 먼저 하이라이트 사각형을 그리도록 했다.
- 하이라이트 색상은 rgba/background-color 값을 읽어 jsPDF fill 색상과 투명도로 변환한다.

관련 파일
- frontend/src/components/PdfJsViewer.jsx
- frontend/src/services/pdfHtmlStructureService.js
- frontend/src/services/pdfHtmlTextConvertService.js


9. 하이라이트 적용 시 검은 네모칸이 생기는 문제 수정
- 원본 하이라이트를 가져올 때 하이라이트 주변에 불필요한 네모칸이 함께 생성되는 현상을 확인했다.
- 원인 후보는 Highlight annotation의 QuadPoints 해석과 line 추출 결과가 하이라이트 경계선처럼 들어오는 경우였다.
- PDF.js 표시 방식에 맞춰 QuadPoints 중 실제 표시 영역 기준점만 사용하도록 수정했다.
- 하이라이트 경계와 같은 위치에 있는 선분은 HTML/jsPDF 재생성 전에 제거하도록 필터링했다.
- 수정 중 발생한 "Cannot access 'lines' before initialization" 오류는 lines 선언 순서를 바로잡아 해결했다.

관련 파일
- frontend/src/services/pdfHtmlStructureService.js

- 변환 오류 발생 시 어느 단계에서 어긋나는지 확인하기 쉽게 만들었다.

13. 현재 남은 확인 사항
- 실제 브라우저에서 "즉시 텍스트 교체" 모달의 "변환 파일 다운로드" 결과를 다시 내려받아 하이라이트 네모칸이 사라졌는지 확인이 필요하다.
